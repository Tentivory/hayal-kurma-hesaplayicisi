# Hayal Kurma Hesaplayıcısı

Bu proje, insanlık tarihinin en büyük sorununu çözmek için yaratıldı: **"Bugün ne kadar hayal kurdum ve bu yüzden kaç bardak çay demleyebilirdim?"**

## Neden Bu Proje Var?

Çünkü hayat çok ciddi. Hayal kurmak ise daha da ciddi. Bu kod, sizin hayal kurma sürenizi alır, onu üretkenlik kaybına çevirir ve size "acaba ben boş mu duruyorum yoksa stratejik mi planlama yapıyorum?" sorusunu cevaplar. Cevap her zaman "stratejik" çıkar. Garanti.

## Nasıl Çalışır?

1. Python çalıştır.
2. Kaç dakika hayal kurduğunu söyle.
3. Kod, bunu "kaybedilen çay demleme fırsatı" olarak hesaplar.
4. Sonunda sana moral verir. Çünkü biz buradayız.

## Özellikler

- Tamamen bilimsel (değil).
- Abartılı ciddi dil kullanır.
- Hiçbir işe yaramaz ama çok havalı görünür.
- Türkçe. Tamamen.

## Kurulum

```bash
python hayal_kurma.py
```

Hepsi bu. Başka bir şey yok. Gerçekten.

## Lisans

Bu kodu çalabilirsin. Zaten kimse kullanmaz. Ama çalarsan en azından "vay be" de.
